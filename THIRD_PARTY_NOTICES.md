# Dependencias de terceros

Este proyecto utiliza las siguientes bibliotecas en el navegador:

- Mammoth.js 1.8.0 - BSD-2-Clause.
- PDF.js 3.11.174 - Apache-2.0. El archivo `assets/vendor/pdf.worker.min.js` pertenece al proyecto Mozilla PDF.js.
- docx 8.5.0 - MIT.
- jsPDF 2.5.1 - MIT.

Consulta los repositorios de cada proyecto para leer el texto completo y vigente de sus licencias.
